Notifications

Users

People who can sign in. Accounts are created here — there is no public sign-up. Admins can manage everything; viewers are read-only.

Backup & recovery

Keep a copy of your master key and database somewhere safe. Restore by putting both files back in the data folder. Lose the key and stored secrets can't be recovered.

The master key is sensitive — store it in a password manager, ideally separate from the database, and only download it over HTTPS.

Security

Two-factor authentication

Add a time-based code from an authenticator app as a second factor at sign-in.

Scan this with your authenticator app (or enter the key), then confirm a code to turn it on.

Secret vault — zero-knowledge

Your passphrase is turned into a key in your browser and never sent to the server, which only ever stores ciphertext. Share the vault by sharing the passphrase — each admin unlocks once per browser session. Forget the passphrase and the stored secrets are unrecoverable.

Trusted certificate (HTTPS)

This server uses a private certificate authority. Install it on a device to make certguard's HTTPS show a trusted padlock instead of a warning.

⤓ Download CA certificate

Windows: double-click → Install Certificate → Local Machine → place in Trusted Root Certification Authorities. macOS: open in Keychain Access → System → set to Always Trust. Linux: copy to /usr/local/share/ca-certificates/ and run sudo update-ca-certificates.
